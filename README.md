# Mango Port — PC games on iPhone, powered by Madeira

Mango Port runs **your own copies of Windows PC games** on a non-jailbroken iPhone or iPad: Fallout 4, Skyrim, Call of Duty: Black Ops and Black Ops II, and every other game [Madeira](https://github.com/willfaust/Madeira) supports, with Far Cry 4 and Ubisoft Connect added on top. It's built on Madeira (Wine + FEX-Emu + DXMT) by Will Faust and its contributors; Mango's look, game profiles and builds are layered on top as small patches.

> **Status: milestone 1 — not device-tested yet.** The profiles are a starting point modelled on Madeira's tested Rockstar Launcher chain. Expect tuning.

## What's in here

| --- | --- |
| `madeira/` | Madeira, pinned as a submodule at a known-good commit (`401a927`) |
| `mango/patches/0001-…profiles.patch` | Far Cry 4 + Ubisoft Connect recommended settings, recognition rules and their host tests |
| `mango/patches/0002-…branding.patch` | App name **Mango Port**, bundle ID `com.mangomods.mangoport` |
| `mango/patches/0003-…download.patch` | Retries for the toolchain download on GitHub's Macs |
| `mango/patches/0004-on-screen-rebrand.patch` | Generated by `scripts/rebrand.py`: "Madeira" becomes **Mango Port** on every screen, "Madeira Dock" becomes "Mango Dock", the mango app icon (`mango/icon/`), and a "built on Madeira" credit in About |
| `mango/patches/0005-mango-main-screen.patch` | The mango main screen: night theme, mango accent colour, wordmark title with a JIT pill, Continue playing card, mango store tabs and rounder cards, mango liquid metal, and the launch screen |
| `mango/patches/0006-mango-details-settings-credits.patch` | "powered by Madeira" under the title, the mango Game details page and Play button, the night Settings page, a Mango Port credit above Madeira's credits, and the mango on the welcome page |
| `mango/patches/0007-mango-start-screen-subpages.patch` | The mango game-start screen (gold spinner, rounded title, mango-lit cover and buttons) and the night theme on every Game details and Settings page |
| `mango/patches/0008-tap-bolt-to-enable-jit.patch` | The grey JIT bolt beside the title enables JIT when tapped |
| `mango/patches/0009-unplayable-games.patch` | Games tested and found unable to run (MangoUnplayable in SteamGames.swift, by Steam App ID): a red "Can't run on iPhone" label, no Install on their Steam page, and Play refuses them |
| `mango/patches/0010-automatic-prefix-fixes.patch` | Fixes Mango Port makes to Windows by itself (MangoPrefixFixes): the empty `system32\mui` and `syswow64\mui` folders Steam's CEG step needs (Black Ops, Black Ops II, Borderlands 2), at every app start and game start |
| `scripts/apply-mango.sh` | Fetches Madeira and applies the patches (idempotent) |
| `scripts/test.sh` | Runs the Madeira host checks the patches touch |
| `docs/` | Roadmap, Far Cry 4 test log, legal notes |

Keeping Mango's changes as patches means pulling a newer Madeira is: bump the submodule, re-run `apply-mango.sh`, fix any patch that no longer applies, then run `scripts/make-rebrand-patch.sh` to regenerate the rebrand patch.

## What the Far Cry 4 profile does

When Mango Port sees Far Cry 4 — by Steam App ID `298110`, a `Far Cry 4` folder under `steamapps\common`, or `FarCry4.exe` anywhere — it applies:

- Madeira's memory-pool lines that let Chromium (CEF) launchers load, since the game starts through **Ubisoft Connect**
- DXMT's small-ring mode for Ubisoft Connect's windows
- Start in the Wine desktop with Windows services first
- 30 FPS cap, fit-to-screen, fast sync
- A 3 GB swap file on iPhones with less than 12 GB of RAM

Ubisoft Connect itself (`upc.exe` / `UbisoftConnect.exe` in its `Ubisoft Game Launcher` folder) and its installer get their own lists.

## Requirements

- iPhone on **iOS 26+** (A15 / iPhone 13 Pro or newer; more RAM is better)
- **JIT** via StikDebug or Madeira's built-in StikJIT helper
- Sideloaded with the **increased memory limit** entitlement intact
- **Your own Far Cry 4** (Steam or Ubisoft Store) and a Ubisoft account. Mango Port ships no game files.

## Build

```bash
git clone --recurse-submodules https://github.com/MangoMods-code/FarCry-4-But-Mango.git
cd FarCry-4-But-Mango
scripts/apply-mango.sh        # full submodule fetch + patches
scripts/test.sh               # host checks
```

**No Mac?** Run **Actions → Build Mango Port IPA** and download the `F4MangoPort-ipa` artifact. Read the cost notes in [`docs/BUILDING.md`](docs/BUILDING.md) first: a cold build takes hours of macOS runner time.

On a Mac, follow `madeira/BUILDING.md` (Xcode, the Wine/FEX/DXMT toolchains). The output is the same IPA Madeira makes, renamed Mango Port.

## Rules this project keeps

- **No game files, ever.** Users bring their own legally owned copy.
- **No DRM bypass.** Far Cry 4 runs through the real Ubisoft Connect, signed in with the player's own account.
- **Open source under GPL-3.0-or-later** with the Madeira Converter Exception, same as Madeira (`LICENSE`, `LICENSE-EXCEPTION.md`).
- **Not affiliated with Ubisoft.** "Far Cry" and "Ubisoft Connect" are Ubisoft's trademarks, used here only to say what the launcher is compatible with. No Ubisoft logos or art in the app.
